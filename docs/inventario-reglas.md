## 1. Sistema base (PbtA)

| ID | Regla |
|----|--------|
| SYS-01 | Resolución: **2d6 + atributo** cuando hay incertidumbre o riesgo. |
| SYS-02 | **10+** = éxito completo (sin consecuencias importantes). |
| SYS-03 | **7–9** = éxito parcial (complicación, coste, elección difícil o consecuencia inesperada). |
| SYS-04 | **6−** = fallo; el Director introduce complicación, más peligro o situación desfavorable. |
| SYS-05 | La historia debe **seguir avanzando** con cualquier resultado (fallos = oportunidades narrativas). |
| SYS-06 | **Movimientos**: se activan con riesgo/incertidumbre/consecuencias importantes; todos pueden intentar cualquier movimiento; la diferencia son **herramientas** (Cromos/Chapería). |
| SYS-07 | **Director**: no compite; presenta desafíos y consecuencias (amenazas, información, seguridad, presión temporal, reacción enemiga en 7–9/6−). |

### Atributos

| Código | Nombre | Uso en tirada |
|--------|--------|----------------|
| EN | Enlaces Neuronales | Inteligencia, análisis, técnica, redes, implantes, sistemas |
| MC | Manipulación Cognitiva | Percepción social, empatía, persuasión |
| RC | Reacción Cinética | Reflejos, coordinación, respuesta bajo presión |
| TM | Tejido Muscular | Fuerza, resistencia, tolerancia al daño/esfuerzo |

## 2. Creación de personaje

| ID | Regla |
|----|--------|
| CRE-01 | Elegir **una profesión** (arquetipo). |
| CRE-02 | **Rasgos iniciales**: aplicar los modificadores EN/MC/RC/TM indicados en la profesión (valores fijos por profesión, ver tabla CRE-T). |
| CRE-03 | **Cyberware inicial**: **1 neuroranura improvisada** (no suma para @Psique), más **2 cromos improvisados** **O** **1 cromo corriente** adicional. |
| CRE-04 | **Chapería inicial**: elegir **2 piezas improvisadas** **O** **1 pieza corriente** que **no** sea de categoría armas. |

## 3. Cromos — humanidad y límites

| ID | Regla |
|----|--------|
| CRO-01 | **Cromo** = implante que reemplaza o mejora el cuerpo; cada implante cuenta como **un** cromo instalado (aunque dé varios bonos). |
| CRO-02 | Escala de **puntos de mejora** a características: +1→1 pt, +2→2 pt, +3→4 pt, +4→8 pt, +5→16 pt, +6→32 pt. |
| CRO-03 | Suma de bonos de cromos por característica: **tope +3** (ninguna característica por encima de +3 por cromos). |
| CRO-04 | **Degeneración neural**: por cada **3 cromos** instalados → reducir **1 punto** en una característica a elección (mínimo **−3**). |
| CRO-05 | Cada penalización por degeneración → marcar **1 casilla @Psique**. |
| CRO-06 | **Pifia** usando característica **mejorada por cromos** → episodio cyberpsicosis **1 turno** + **1 casilla @Psique**. |
| CRO-07 | @Psique **1–3** casillas: episodios breves. **4–5**: cyberpsicosis mayor toda la escena. **>5**: cyberpsicópata permanente, control del Director. |
| CRO-08 | **Retirar cromo**: pierde beneficios; elimina **1 casilla @Psique**; reinstalar sin tratamiento vuelve a subir @Psique; improvisados destruidos en conflicto al retirar (reparables por biohacker). |
| CRO-09 | **Tratamiento psicológico digital**: **1 día** = −1 casilla @Psique; recuperar 4.º y 5.º nivel @Psique = **1 semana** tratamiento avanzado + **trastorno permanente** (narrativa/Director). |
| CRO-10 | **Neuroranuras** (cromo): no suman para @psicosis (texto original). |

## 4. Economía — Neurodata, Estrellas, Créditos

| ID | Regla |
|----|--------|
| ECO-01 | Tras misión o vivencia significativa: volcar experiencia → **Neurodata** en terminal compatible. |
| ECO-02 | **Tasador Virtual** evalúa Neurodata → paga en **Estrellas**. |
| ECO-03 | **1 Estrella por criterio cumplido** (máx. 4 por evaluación típica): sobrevivir misión; aprender algo nuevo/relevante; grupo cumple objetivo principal; participar en **Escena Estrella** (elegida por jugadores al final de sesión). |
| ECO-04 | **1 Estrella = 1 Crédito**. |
| ECO-05 | Créditos se **acumulan** hasta gastarlos. |
| ECO-06 | Precio pieza **nueva** (incluye 1 subsistema básico): Improvisado **5**, Corriente **10**, Hi-Tech **15**, Militar **20** créditos. |
| ECO-07 | **Mejorar** pieza: entregar anterior; pagar solo **diferencia** entre categorías; sin deterioro extra por reemplazo. |
| ECO-08 | Coste **1 Crédito** cada uno: subsistema nuevo, accesorio, pack 8 granadas, cargador balística exótica (Director puede igualar otros consumibles similares). |
