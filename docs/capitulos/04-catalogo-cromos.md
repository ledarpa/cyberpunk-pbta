# Cromos

## Cómo leer las entradas

- Cada entrada de implante es un cromo (cuenta para carga de implantes y @Psique, salvo donde diga lo contrario).

- Las líneas con > son módulos u opciones que ocupan huecos del implante modular.

- Improvisado / Corriente / Hi-Tech / Militar = calidad (coste de pieza nueva: 5 / 10 / 15 / 20 Créditos).

## Cyberópticas

### Ojo biónico

Glóbulo + músculos + chip de asistencia. Con el ojo apagado pero funcional, enciende pasivo el colorimétrico convencional.

- Cada ojo = un cromo (puede haber más de dos, en cualquier parte del cuerpo).
- Módulos del mismo ojo funcionan juntos; módulos de otros ojos son independientes.
- Implante modular.

| Calidad | Módulos disponibles |
| --- | --- |
| Improvisado | 1 |
| Corriente | 2 |
| Hi-Tech | 3 |
| Militar | 4 |

| Módulo | Efecto |
| --- | --- |
| Colorimetría de banda ancha | Más colores; detecta láseres de seguridad. **+1 MC** |
| Fotosensor | Evita ceguera por luz extrema; adaptación rápida a penumbra. **+1 RC** |
| Filmadora | Vídeo en la cyberóptica |
| Inalámbrico | Ojo desmontable a distancia; rango 10 m (mejora con conexión neuronal inalámbrica) |
| Película protectora | Protege cavidad; vista digital en paralelo (una, otra o ambas). **+1 TM** |
| Reconocimiento facial | Info de BD cargada + estadísticas al observar. **+1 MC** |
| Captura 3D | Reconstrucción de escenas para holograma o PC. **+1 EN** |

| Seguimiento de microexpresiones | Detección asistida de microexpresiones. **+1 MC**; redundancia: +1 módulo y +1 mejora MC por redundancia |
| Zoom óptico | **×10 por módulo**; duplica alcance de disparos |

## Cyberextremidades

Adaptadores nerviosos, musculares y óseos desde la base del hombro (o equivalente).

- Varios cyberbrazos o cyberpiernas: uno por extremidad biológica amputada.

- Excepción: módulos de extremidad adicional en cybervértebras → hasta 4 extremidades extra (según implante).

- Extremidad que reemplaza biológica = un cromo; montadas solo en cybervértebras → cuenta el cromo vertebral, no uno extra por brazo/pierna.
